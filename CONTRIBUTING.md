# Contributing

Senlay World is the public product website for Senlay. It is not currently an open contribution project, but carefully scoped feedback is welcome.

## Good Contributions

- broken links
- typos or unclear public copy
- accessibility issues
- small documentation improvements
- clear bug reports for public pages

## Please Do Not Submit

- production secrets
- database snapshots
- private founder or family media
- raw backup archives
- generated bulk rewrites
- large unreviewed asset dumps

## Content Standard

Public content should sound clear, grounded, and useful. Avoid hype, filler, and overly technical language where a simpler explanation works.
