# Senlay World

Public website and landing pages for Senlay.

Senlay is the sensory intelligence layer for AI agents: live physical-world context from weather, ocean, terrain, air-quality, and other sensor sources.

## Contents

- `index.html` - main landing page
- `founder.html` - founder bio page
- `docs.html` - public API documentation
- `demo.html` - public demo page shell
- `agents.html` - AI agents page
- `moltbook.html` - Moltbook agent page
- `pricing.html`, `support.html`, `roadmap.html`
- `landing.css`, `style.css`, `landing.js`, `app.js`
- `founder-selected/` - selected public founder/story images
- logos, icons, and public assets

## Notes

This repository is safe to make public. It should not contain production `.env` files, databases, backup archives, API keys, or server-only runtime data.

Some pages call live Senlay API routes. Those features need the private platform backend to be running.
