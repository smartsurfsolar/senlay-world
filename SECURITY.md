# Security

This public repository should never contain secrets or production runtime data.

## Never Commit

- `.env` files
- API keys or tokens
- private SSH keys
- SQLite databases
- production backups
- server logs
- raw customer or user data

## Reporting

If you find a security issue in the public website or notice sensitive material in the repository, contact:

[smartsurfsolar@gmail.com](mailto:smartsurfsolar@gmail.com)

Please avoid opening a public issue for sensitive findings.
