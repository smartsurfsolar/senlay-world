# Asset Policy

The public website uses selected images to support the founder story and product credibility. Assets should be curated, named clearly, and kept in organized folders.

## Public Asset Folders

```text
public/assets/brand/
public/assets/founder-selected/
```

## Keep Public

- logos
- icons
- selected founder story images already used by the website
- small public screenshots or product visuals

## Keep Private

- raw photo/video dumps
- unused founder media
- private family media
- certificates not meant for public distribution
- production backups
- source files with secrets or metadata

## Before Adding New Images

Check:

- Does the image support the public story?
- Is it appropriate for investors, developers, and customers?
- Is the file size reasonable?
- Is the filename readable?
- Is the image referenced by a page?

If the answer is no, keep it out of the public repository.
