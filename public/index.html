“Physical senses” is shorthand. Senlay doesn't give AI biological perception — it gives agents live telemetry, source provenance, freshness, distance, confidence, and evidence metadata.

Why AI Agents Need Physical-World Context

Most AI agents reason from training data, forecasts, and static knowledge. They can solve differential equations but don't know whether a drone can safely launch in the next 20 minutes at a specific coast, or whether the swell a sailing agent is planning around is already building. Senlay bridges the gap between digital reasoning and measured reality.

How does the agent know?

Every physical-world claim needs evidence. Senlay does not only answer “what is happening?” — it exposes how we know.

Most AI systems
  • Answer from training data
  • Quote forecasts without timestamps
  • Infer from static knowledge
  • No source, no freshness, no confidence
Agents using Senlay
  • See the source type (sensor / model / satellite / report)
  • See the timestamp and distance to the source
  • See whether nearby sources agree
  • See whether forecast disagrees with live measurement
  • Receive interpretation + confidence, not just numbers

The future of AI is not only better answers. It is better evidence behind the answer.

The Senlay Evidence Object

Every physical-world claim Senlay returns is structured as a traceable evidence object — claim, source, freshness, confidence, disagreement, and interpretation. One unit of physical-world truth, with the paperwork attached.

Measured Telemetry
Physical instruments measuring reality. METAR stations, ocean buoys, tide gauges, AQ monitors. Ground data, subject to distance and freshness.
🛰️
Satellite Observation
Remote observation. Sentinel-2 imagery, cloud cover, land use, coastline change. Broad coverage, typically delayed.
🧮
Model / Forecast
Physics-based predictions. Open-Meteo, GFS, ECMWF. Global coverage but estimates, not measurements.

When hardware and models disagree, trust hardware — but expose the disagreement. Senlay's current_source field tells your agent exactly which fields were overridden by live sensors and by which station.

Early Access · Build-in-Public

The Modifier Engine is still early.

Senlay today includes working demos of basic physics-based calculators and early environmental modifier logic — terrain-wind hints, wave modifiers, temperature lapse, gust-factor analysis, hazard flags. These demos show the direction of the Physical World Model.

They are not yet a complete, validated physical simulation engine. Advanced modifiers — terrain-aware wind, coastal risk, drone turbulence, agriculture microclimate, multi-source confidence scoring, and sensor/model disagreement detection — require further engineering, calibration, and validation.

The goal isn't to pretend every cliff, current, rotor zone, wave system, or microclimate is already modelled. The goal is to build the first working bridge from raw environmental data toward provenance-aware physical reasoning for AI agents — and to do it in the open.
