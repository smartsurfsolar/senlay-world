Questions

When will paid plans launch?

We're in open beta while the API is validated with real developer and pilot usage. Paid plans will launch when limits, support expectations, and production reliability are clear.

Will free tier always exist?

Yes. A free tier with reasonable limits will remain available so developers can test physical-world context before buying.

What counts as an API call?

One call to /api/v1/pwm = one API call. This returns the Physical World Model — live and model data, source/freshness metadata, confidence signals, interpretation, and a context_string ready for any LLM.

Can I use Senlay commercially during beta?

Yes, for prototypes and pilots. For production or safety-critical deployments, talk to us first so we can define reliability, fallback behavior, and support expectations.

Who is Senlay priced for first?

First paid customers are teams building AI agents or applications where physical conditions affect a real decision: drones, outdoor work, agriculture, marine routing, coastal safety, and field operations.

Need higher limits or pilot access?

If you are evaluating Senlay for drone, outdoor work, agriculture, marine, or safety software, contact us for beta limits, pilot support, and launch pricing.
