Questions

When will paid plans launch?

We're in open beta while the API is validated with real developer and pilot usage. Paid plans will launch when limits, support expectations, and production reliability are clear.

Will free tier always exist?

Yes. A free tier with reasonable limits will remain available so developers can test spot-level verification before buying.

What counts as an API call?

One authenticated verification request to /api/v1/pwm counts as one account request, including cache hits. Daily usage is shared across all active API keys on the account. The endpoint returns available live and model data, source/freshness metadata, confidence signals, interpretation, uncertainty, and structured evidence for software or AI workflows.

Can I use Senlay commercially during beta?

Yes, for prototypes and pilots. Production and safety-critical deployments require pilot discussion, reliability expectations, fallback behavior, and domain validation.

Who pays first?

Contributors do not pay cash — a sensor is the payment, and what they receive back is coverage, not revenue. The closest paid buyer is a system that acts on the answer and will never install hardware: drone operators, robotics fleets, lifting and construction, parametric insurers, marine operations, SmartSurf schools and stations, and IoT teams that need to explain a physical-world alert. The two sides do not compete for the same budget.

If I contribute a sensor, do I still need a paid plan?

Contributor access is arranged during pilot onboarding. Registering a station does not automatically change your API tier or remove account limits. Contact Senlay to agree the contributor allowance and any additional API access your operation needs.

Need higher limits, risk_event support, or pilot access?

If you are evaluating Senlay for SmartSurf-style safety, drone, outdoor work, agriculture, marine, SAR, or IoT software, contact us for beta limits, risk-event design, fallback behavior, pilot support, and launch pricing.
