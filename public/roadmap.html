Roadmap

Senlay is a reciprocal verification network for systems that act outside — AI agents, drones, robots, and safety systems. Coverage arrives from participants: contribute a sensor and get the whole network back. SmartSurf is the proving ground: rider and board GPS, local spot intelligence, tracker control, risk events, and station workflows, validating the same evidence engine that reasons across every contributed and connected source.

LIVE Open contributor network + Senlay evidence engine
  • Open protocol, JS SDK, MQTT bridge, edge gateway published Apache 2.0 at senlay-platform
  • Provider/station registration + HMAC-signed observation ingestion, validating independently at each stage
  • Controlled source-health status: ok, no_data, out_of_coverage, not_configured, error, timeout — a source dark for a missing credential is labelled as such
  • risk_event endpoints for station, lifeguard, IoT, and audit workflows
  • model-vs-reality disagreement detection
  • first water-safety use case: rider/board GPS + environmental evidence + station escalation
NEXT 30 DAYS Signed evidence, external usage, first outside integrations
  • Signed evidence receipts: every response signed over its hash, issue time, coordinate, source set, and calling key — a citable, tamper-evident record, zero added friction, works for anonymous callers
  • OGC SensorThings adapter: import Things/Sensors/Datastreams/Observations from an existing SensorThings endpoint without touching the provider's hardware — turns "attach a sensor" into "attach the network you already run"
  • External API keys issued to people outside the company, tracked honestly as the decisive early proof
NEXT 60 DAYS SmartSurf Safety Engine architecture
  • SmartSurf Safety Engine architecture
  • Live Tracker / Spot Intelligence UI mode
  • stopped rider, offshore drift, board separation triggers
  • tracker command registry
  • battery/signal-aware device modes
  • Senlay snapshot attached to each risk_event
NEXT 90 DAYS Station workflow and pilot readiness
  • first school/station pilot
  • station dashboard workflow
  • acknowledgement / escalation / incident log
  • phone-first rider app MVP
  • local spot_profile for Hoi An / An Bang / Mui Ne / Phan Rang pilot spots
NEXT 12 MONTHS Paid station pilots and dataset growth
  • paid station pilots
  • proprietary safety dataset from sessions and alerts
  • expanded spot intelligence for surf, SUP, foil, sailing
  • Senlay API as second channel after SmartSurf proof
LATER Platform expansion
  • Universal LLM compatibility
  • Multi-agent shared world model
  • Any coordinate on Earth
  • Digital twin integration
  • Broad autonomous systems
