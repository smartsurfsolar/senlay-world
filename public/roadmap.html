Roadmap

Where Senlay is today and where we're heading. Now / Next / Later, kept honest.
Built in public by a solo founder.

LIVE Core Platform
  • ✅Physical World Model API — real-time environmental data for any coordinate on Earth via single REST endpoint
  • ✅21 sensor sources — Open-Meteo models, METAR aviation stations, NDBC ocean buoys, NOAA tides, USGS seismic, Sentinel-2 satellite, NWS observations, air quality, water temperature, space weather, radiation monitoring, and more
  • ✅110 curated sensor locations — global coverage across 6 continents, plus city search for any location
  • ✅Early Modifier Engine — working demos of physics-based calculators: terrain-wind hints (ridge speedup, lee rotor, valley channeling), wave modifiers (shoaling, breaking cap), temperature lapse, gust-factor analysis, hazard flags. Proof-of-direction, not yet a fully validated simulation engine.
  • ✅Source & freshness metadata — every PWM response surfaces current_source per layer, including which fields were overridden by live hardware vs. model.
  • ✅Calculated Insights — Beaufort scale, gust factor analysis, wave energy index, wind trends (past + forecast), model vs hardware cross-reference, hazard flags
  • ✅Expert AI system prompt — kitesurfing safety scoring, kite size recommendations, red flag system, session timing intelligence
  • ✅Claude tool calling — AI can dynamically refresh sensors for different locations mid-conversation
  • ✅Developer tools — API key management, PWM sandbox, unit conversion (metric/imperial/knots/m·s), system health monitor
  • ✅Universal LLM compatibility — works with Claude, GPT, Gemini, Llama, Mistral — any model that accepts a system prompt
BUILDING Q2 2026
  • 🔧Senlay Evidence Object (v1) — structured per-claim payload: source type, source id, distance, freshness, confidence, model disagreement, interpretation, uncertainty. Promotes context_string from prose to traceable evidence.
  • 🔧Confidence scoring & freshness decay — per-field confidence levels that decay with distance and time-since-measurement. Sensor agreement metrics across nearby stations.
  • 🔧Sensor / model disagreement detection — explicit flags when live measurement diverges from forecast, with delta and direction.
  • 🔧Modifier Engine v1 (validated) — promote the early demos into calibrated terrain-wind, wave, coastal and microclimate modifiers with documented assumptions.
  • 🔧Self-hosted weather models — run Open-Meteo locally for unlimited API calls, zero dependency on external rate limits.
  • 🔧Historical data layer — “what were conditions here 3 hours / 3 days / 3 months ago?” for trend analysis and anomaly detection.
  • 🔧Webhook alerts — “notify me when wind at Tarifa exceeds 20 km/h” — condition-based push notifications for AI agents.
  • 🔧Expanded METAR coverage — target 100% of curated sensor locations backed by live hardware airport data.
PLANNED Q3–Q4 2026
  • 📋Domain Pack: Marine / Watersports — coastal risk modifiers, sea-state interpretation, rider/board safety logic. Senlay's first validated domain pack — built on the SmartSurf proving ground.
  • 📋Domain Pack: Drones — pre-flight environmental assessment endpoint for UAS/eVTOL: terrain-aware wind at altitude, turbulence/exposure logic, visibility, no-fly conditions.
  • 📋Domain Pack: Agriculture — spray-drift risk, frost prediction, evapotranspiration, soil-moisture proxy, UV crop stress — precision-farming context without dedicated hardware.
  • 📋Maritime routing layer — ship fuel optimisation, wave-current interaction, sea-spray visibility, port-approach wind assessment.
  • 📋Plausibility / spoofing checks — physical-plausibility tests on incoming readings; flag manipulated, stuck, or contextually impossible values before they reach the agent.
  • 📋Multi-agent shared world model — multiple AI agents subscribing to the same location get a synchronised, evidence-tagged environmental picture.
  • 📋SDK packages — Python, JavaScript, Go client libraries for faster integration.
PLANNED Q1–Q2 2027
  • 🧭Skipper Intelligence — teaching LLMs to interpret bathymetry and wind shadows. AI agents will read the ocean floor, coastlines, and terrain the way experienced skippers do — anticipating choppy water, lee zones, and channel effects from geometry alone.
  • 📡100+ Certified Ground Truth nodes — expansion of verified, high-precision sensor nodes in high-risk maritime zones: Cape of Good Hope, Strait of Gibraltar, Tsugaru Strait, Drake Passage, Malacca Strait. When life is on the line, AI needs data it can trust.
FUTURE 2027+
  • 🔭Federated sensor network — any IoT device can contribute data to the Physical World Model. SmartSurf hardware trackers as first-party sensors.
  • 🔭P3 Modifiers — soil conditions, acoustic propagation, electromagnetic/comms interference, building-level urban wind, solar farm optimization
  • 🔭Insurance & parametric triggers — verified microclimate data for parametric weather insurance, claims verification, property risk scoring
  • 🔭Digital twin integration — real-world state sync for simulation environments, RL training, autonomous system validation
  • 🔭Universal Physical World API — the endgame: one API call returns complete physical reality for any coordinate, any altitude, any time. The "Google Maps for environmental intelligence."

The Mission

Building a world where AI protects humans from physical hazards it can finally see.
